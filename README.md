### 📦 최신 릴리스

[최신 유저 설치 파일과 업데이트 내역은 GitHub Releases에서 확인할 수 있습니다.](https://github.com/daydreamrabbit/metadata-manager-releases/releases/latest)

1. **[최신 배포판](https://github.com/daydreamrabbit/metadata-manager-releases/releases/latest)**에서 `Metadata-Manager-User-…-x64.exe`를 다운로드합니다.
2. 설치 후 실행하고 사용 전 공지를 확인합니다.
3. 설정에서 기본 폴더와 검색·경로 규칙을 지정합니다.
4. 파일을 불러와 정보를 검색하고, 결과를 확인한 뒤 메타데이터를 저장합니다.

Windows x64 설치판입니다. Node.js나 Git은 별도로 설치하지 않아도 됩니다. PDF 처리 등 일부 기능에는 Python 및 calibre, rclone 이동에는 rclone 같은 외부 도구가 필요할 수 있습니다.

### 🔄 업데이트

설치판은 실행 시 새 유저 버전을 확인합니다. 변경 내용을 확인한 뒤 다운로드와 설치를 선택할 수 있습니다. 상단 버전 메뉴의 **업데이트 확인**으로 직접 확인할 수도 있습니다.

`latest.yml`과 `.blockmap`은 자동 업데이트용 파일입니다. 직접 설치할 때는 `.exe`만 받으세요.

### 📌 사용 전 확인

> 이 프로그램은 **로컬 파일의 메타데이터 관리용**입니다. **GDS에서 사용하거나 GDS에 연결된 자료·경로를 대상으로 테스트하지 마세요.** 최초 실행 시 동의해야 사용할 수 있습니다.
